# Трекер подписок и гарантий (Subscription & Warranty Tracker)

Локальное веб-приложение на FastAPI и SQLite для учета регулярных подписок, хранения чеков и контроля сроков гарантии на купленные товары.

## Возможности

- Учет подписок: стоимость, валюта, периодичность списания (ежемесячно, ежегодно, произвольный интервал в днях), статус (активна, на паузе, отменена), прямая ссылка на страницу отмены подписки.
- Автоматический пересчет совокупных расходов на активные подписки в месяц и в год.
- Продление даты следующего списания в один клик с учетом календарных месяцев (`dateutil.relativedelta`).
- Учет гарантийных сроков: магазин, дата покупки, дата окончания гарантии, серийный номер, стоимость и прикрепленный файл чека (`.pdf`, `.png`, `.jpg`, `.jpeg`, `.webp`).
- Панель скорых событий: предупреждения о предстоящих списаниях и истекающих гарантиях за заданное число дней.
- Фоновая проверка напоминаний через `APScheduler` и опциональная отправка уведомлений в Telegram при заданных переменных окружения.

## Установка и запуск

1. Создайте и активируйте виртуальное окружение Python 3.11+:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. Запустите сервер приложения:

```powershell
python run.py
```

3. Откройте в браузере адрес `http://127.0.0.1:8000`.

## Настройка через переменные окружения

При необходимости скопируйте `.env.example` в `.env` или задайте переменные окружения перед запуском:

- `TRACKER_HOST`: адрес привязки сервера (по умолчанию `127.0.0.1`).
- `TRACKER_PORT`: порт сервера (по умолчанию `8000`).
- `TRACKER_DB_PATH`: путь к файлу базы данных SQLite (по умолчанию `data/tracker.db`).
- `TRACKER_UPLOADS_DIR`: каталог для хранения загруженных чеков (по умолчанию `data/uploads`).
- `TRACKER_ENABLE_SCHEDULER`: запуск фонового планировщика проверок (`1` или `0`, по умолчанию `1`).
- `TRACKER_TELEGRAM_BOT_TOKEN` и `TRACKER_TELEGRAM_CHAT_ID`: параметры для отправки уведомлений в Telegram.
